Icon Requirements for Thunderstore
===================================

For publishing to Thunderstore, you need an icon.png file with these specifications:

- Format: PNG
- Dimensions: 256x256 pixels
- File size: Under 1MB
- Content: Should represent the mod (e.g., two shapez logos connected, multiplayer symbol, etc.)

Suggested Design:
- Background: Dark blue/purple gradient
- Foreground: Two connected factory/shape icons
- Text: "MP" or "Multiplayer" badge
- Style: Match Shapez 2's visual aesthetic

You can create this using:
- Adobe Photoshop
- GIMP (free)
- Figma (free)
- Canva (free)
- Any image editing software

Place the final icon.png file in this directory before packaging for Thunderstore.
